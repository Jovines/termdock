# 3D 模型语义特征清单 (model-features)

web-terminal 3D 查看器「特征标注」的可选增强数据契约。

- **通用点选引用**(点模型任意位置)不依赖本数据, 任何模型都可用;
- 本数据只负责提供**命名的面/棱/边/角**, 让引用更友好、选中更高亮;
- 文件位置: `<模型目录>/features/<模型文件名去后缀>.json`
  (如 `glb/assembly.glb` → `features/assembly.json`);
- 格式: [model-features.schema.json](./model-features.schema.json)(契约唯一出处,
  `version` 递增表示破坏性改动);
- 坐标: CAD 场景坐标(Z-up), 与模型文件一致; 查看器内部做 (x,y,z)→(x,z,-y) 转换。

生产方可以是 cadquery-print skill、其他工具或手写——查看器只认契约, 不认生产方。

## 引用文本格式

查看器把选中位置插入对话/草稿时, 统一用双引号框住的 `"模型标注: …"` 文本, 供其他 Agent 结合模型文件定位:

- **通用点选**: `"模型标注: <模型绝对路径> / 部位: <零件名> / 点 (x,y,z)mm [<坐标系>] / 法线 (nx,ny,nz)"`；
  有 features.json 且命中近邻特征时追加 `≈ <零件>·<特征名>` 或 `≈ 靠近 <零件>·<特征名>`。
- **特征引用**: `"模型标注: <模型绝对路径> / 面A: <零件>·<特征名> (中心 x,y,z)mm [<坐标系>] / 命中距离 <d>mm ; 面B: …"`。

约定:

- 整段标注用双引号包裹, 与其他文本区分开;
- `<模型绝对路径>` 是查看器打开的模型文件绝对路径, 其他 Agent 可直接按该路径读取 GLB/STL;
- 点/法线/中心只给**被引用文件自己坐标系**的一个值, 单位 mm, Agent 直接读该文件即可对上:
  - `.glb`/`.gltf` → `[GLB 世界坐标 Y-up]`(按 glTF 规范加载、应用节点变换后的世界坐标, CAD (x,y,z) → (x,z,-y));
  - `.stl` → `[STL 文件坐标 Z-up]`(文件里原样存的坐标, 无场景变换);
- 内部 features.json 仍统一用 CAD 场景坐标(Z-up), 文本输出时才按引用文件转换;
- 点选的点恒在表面, 不写命中距离; 特征引用里中心可能离面, 距离 >0.05mm 时写
  `命中距离 <d>mm`;
- `部位` 是 GLB 节点名(如 `base_1`), features.json 存在时映射为零件中文名。
