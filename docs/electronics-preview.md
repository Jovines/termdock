# 电子设计文件预览与标注

Termdock Review 支持直接查看 KiCad 源文件并把问题位置引用到对话或上下文草稿。

## 支持格式

- `.kicad_sch`：使用本机 `kicad-cli` 渲染原理图第 1 页 SVG。
- `.kicad_pcb`：可切换 PCB 正面、镜像背面和可交互 3D 视图；3D 视图支持旋转、平移、缩放、剖切及点选元件。
- `.kicad_pro`：显示工程格式、网络类、默认间距/线宽/过孔和 DRC 排除项，并可逐项引用。
- `.kicad_prl`：显示本机编辑器状态摘要并明确提示它不属于电气设计源文件；需要时仍可展开原始 JSON。
- `.csv`：以冻结表头的可滚动表格显示 BOM、接口表和候选器件表；点击单元格可引用列、值与完整记录。
- 固件、BOM、接口表和 Markdown：继续使用通用文本预览，可选择一行或多行引用。

## 电子标注

在原理图或 PCB 渲染图中点击问题位置，再点击“引用电子标注”，插入以下格式：

```text
"电子标注: <绝对文件路径> / 视图: <PCB正面|PCB背面（镜像）> / 图片位置: (x%,y%) [相对渲染图左上角] / PCB坐标: (x,y)mm [KiCad板坐标] / 显示层: <层> / 最近对象: <位号/焊盘/走线/过孔>（网络、对象层、距离）"
```

百分比坐标相对于实际渲染图，不相对于包含留白的 Review 面板，因此不同屏幕尺寸仍能定位同一位置。PCB 正面和镜像背面还会读取 KiCad 板框、器件、焊盘、走线与过孔，换算真实毫米坐标并返回最近对象。背面镜像坐标会自动反向换算回 KiCad 工程坐标。

PCB 3D 视图由 KiCad 导出 GLB，按 1000 倍换算为毫米。启用点选后可引用三维命中点、表面法线以及 KiCad GLB 中保留的元件位号；坐标明确标为“KiCad 3D 导出坐标 Y-up”，不冒充二维 KiCad 板坐标。原理图仍只输出图片百分比。

## 实现边界

- 渲染通过 `execFile` 传递参数，不经过 shell。
- 源文件先通过工作区路径校验。
- 每次渲染使用独立临时目录，响应结束后删除。
- 单次导出最长 30 秒，输出沿用预览 20 MB 上限。
- 这项功能用于 Review 和问题定位，不替代 ERC、DRC 或制造发布检查。
