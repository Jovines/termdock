# 通用装配模型查看

GLB/GLTF 有多个独立装配节点时，3D 工具栏显示「爆炸展开」。选择 X/Y/Z
（查看器坐标）、拖动展开程度，点击「恢复装配」回到原位置。单件 STL 或单网格
模型不提供展开；不会把一个零件的不同材质当成多个零件拆开。

展开只是显示位移，不写回模型，不代表实际拆卸顺序或无碰撞拆装路径。
尺寸始终显示原始装配尺寸。展开与剖切互斥，换文件或重新加载回到装配状态；
全屏切换保留当前展开程度。

点选、特征标记和选中圆环跟随部件；引用仍记录原装配坐标、原始部件名和法线。
展开截图附有状态标记，文字引用也注明展开方向和程度，不把展示间隙当成实际间隙。
插入走现有直接插入能力，不增加“审阅引用”确认弹窗，也不会自动发送消息。

自动分组采用 glTF 场景的首个装配分支，保留其子组（子装配）整体。
缺失装配层级、多个零件已烘焙到同一网格时，需要源端重新导出；查看器不猜测网格
的真实机械分件。GLB 名称中的空格保留在引用里，不使用渲染器内部改写名。

## 验证

- `modelExplosion.test.ts`：部件分组、材质子网格、嵌套旋转/缩放、手工矩阵、反复复位、原几何与配色不变。
- `reviewReference.test.ts`：截图附上展开状态，窄图自动换行。
- `RightSidebarModel3dPreview.test.tsx`：既有加载、特征、材质及手势回归。
- `insertDirectReference.test.ts`：直接插入、超时回退、会话切换保护；不在真实终端发送测试消息。

硬件数字检查、实物试配/上电、原厂器件模型完整性不由查看器替代。
